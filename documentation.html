1. Executive Summary & Overall Architecture

SS Supermarket is an enterprise full-stack e-commerce web platform engineered for groceries, fresh farm produce, dairy, bakery, daily essentials, and consumer electronics retail. The platform incorporates multi-role authentication (Buyers, Sellers, Admin), real-time database persistence across local and cloud environments, shopping cart session management, transactional checkout with inventory locks, seller inventory control, an AI Shopping Assistant, and dark/light mode customization.

2. Module 1: Authentication & Role-Based Security

The security module handles identity management and enforces strict resource isolation among buyers, sellers, and administrators.

  • Dual Login Modes: Supports standard email/password authentication and passwordless 6-digit OTP verification with 60-second cooldown timer.
  • Password Protection: Passwords hashed with BCryptPasswordEncoder (strength 10). Plaintext passwords are never persisted.
  • Password Visibility Toggle: Added interactive eye-icon button on login and registration pages that switches input type between password and text.
  • Post-Login Role Dispatcher: CustomAuthenticationSuccessHandler routes users post-login: Buyers → /products | Sellers → /seller | Admins → /admin.
Route Pattern Methods Authorized Roles Access Description

/login, /register GET, POST Permit All User authentication, passwordless OTP requests, and account creation.

/admin/**, /api/admin/** GET, POST ROLE_ADMIN Platform oversight: user management, global sales volume, and product moderation.

The database module dynamically resolves database credentials via DatabaseConfig.java, enabling smooth portability between local MySQL, cloud PostgreSQL on Render, and testing H2 in-memory databases.

4. Module 3: Product Catalog & Category Hierarchy

The catalog module provides the core buyer browsing experience, handling multi-attribute search queries, category hierarchies, real-time stock status, and customer star ratings.

  • 40+ Active Products: Comprehensive supermarket items across fresh produce, organic milk, bakery, household essentials, and electronics.
  • Star Rating Display: Every product card features gold stars and customer ratings out of 5 (e.g., ★★★★★ 4.7 / 5.0 (42 reviews)).
  • Advanced JPQL Search: ProductRepository.searchLegacy() simultaneously queries across product title, brand, description, and categories.
  • Stock Availability Badges: In Stock (stock > 10), Only X Left (1 ≤ stock ≤ 10), Out of Stock (stock = 0, Add to Cart disabled).
  • Seller Transparency: Every product card identifies the merchant's trade name and customer care contact number.

5. Module 4: Shopping Cart & Inventory Validation

Maintains buyer cart states in the database so carts persist across browser refreshes and multiple devices.

  • Real-time Stock Capping: Automatically validates cart additions against available inventory; prevents adding more items than currently in stock.
  • Price & Tax Rules: Subtotal is calculated dynamically; standard supermarket GST (5%) is applied; delivery is FREE for orders ≥ ₹499 (nominal ₹30 fee otherwise).
  • Global Counter: GlobalModelAdvice dynamically updates the shopping cart badge in the navigation bar on every page.

6. Module 5: Checkout, Payment & Order Processing

The checkout module manages order placements within atomic database transactions (@Transactional) with concurrency locks to guarantee data consistency.

Transactional Checkout Workflow

  1. Buyer specifies shipping address and chooses preferred payment method on /checkout.
  2. OrderService.checkout() executes inside an ACID transaction:
    • Validates that the buyer's cart is non-empty.
    • Acquires pessimistic write lock (SELECT ... FOR UPDATE) on product inventory to avoid race conditions.
    • Deducts item quantities from product stock.
    • Saves the Order record with status CONFIRMED.
    • Creates snapshot OrderItem rows recording price at purchase time.
    • Creates Payment ledger record.
    • Clears the buyer's shopping cart items.
  3. Redirects to /order-success displaying a complete, printable customer invoice.
Payment Method Type Transaction Handling
Cash on Delivery (COD) Cash / Offline Order created with payment status PENDING until physical package delivery.
UPI (Google Pay, PhonePe, Paytm) Instant Digital Instant digital intent execution with payment status SUCCESS.
Credit / Debit Cards Card Gateway Card authorization and processing.
Net Banking Bank Redirection Direct bank gateway transfer.

7. Module 6: Seller Portal & Multi-Vendor Inventory

Allows verified merchants (ROLE_SELLER) to independently publish catalog items, update prices, adjust inventory, and view sales performance.

  • Merchant Analytics: Live metric cards display merchant's listed product count, order volume, and gross sales revenue (₹) with null safety.
  • Add Product Form: Merchants submit title, brand, category, price, stock, description, and image URL. Items publish immediately to the buyer storefront.
  • HTML5 Modal Editing: Edit button uses HTML5 data attributes (data-id, data-name, data-price, data-stock) eliminating Thymeleaf SpEL parsing errors. Modal updates fields in place.
  • Deactivation / Deletion: Merchants can deactivate or delete products with cascading integrity checks.
  • Customer Purchases Table: Real-time breakdown of recent customer orders containing the merchant's products.

8. Module 7: Super-Admin Administration Console

Provides system governance and moderation controls for admin@sssupermarket.com:

  • Platform Analytics: High-level visibility into total registered accounts, active sellers, order volume, and aggregate platform revenue.
  • User Governance: Inspect all registered buyers and sellers, update roles, or elevate buyers to sellers.
  • Catalog Moderation: Inspect and moderate any product listed across all independent merchants.

9. Module 8: AI Shopping Assistant & Chatbot

Provides a floating conversational assistant (🤖 Ask AI) on all pages to answer product queries, suggest top-rated items, and explain store policies.

  • Product Lookups: Queries ProductRepository in real-time to answer questions about any product's price, stock, ingredients, and rating.
  • Top-Rated Recommendations: Automatically filters items with ratings $\ge$ 4.5 when users ask for recommendations.
  • Budget Parsing: Extracts budget limits (e.g., "items under ₹100") and returns matching products.
  • Customer Service Guidance: Answers questions regarding 30–45 minute local delivery, free delivery thresholds (₹499), 24-hour return policy, and payment modes.
  • Interactive UX: Includes quick prompt chips, auto-scrolling message window, and Markdown rendering with emojis.

10. Module 9: UI/UX & Dark / Light Theme System

Built on custom CSS properties (variables) with persistent light and dark modes:

  • Zero-Flash Anti-Flicker: An inline script in the <head> of layout.html checks localStorage.getItem('ss_theme') before rendering, avoiding white flashes.
  • CSS Variable Architecture: Standard :root variables are swapped smoothly when [data-theme="dark"] is active on the root document.
  • One-Click Navbar Toggle: Theme button (🌙 / ☀) allows instant switching with state saved across all pages.
